# moydodr-art

Эталонные листы персонажей и готовые панели комикса «2061: Одиссея Три» (графический пересказ, третья редакция). Рисунки сгенерированы моделью Nano Banana 2.1 по оригинальным описаниям — см. `sheets/README.md`.

- `sheets/` — листы персонажей и кораблей (утверждены 5 ноября 2026; `ship_galaxy_v2.png` заменяет `ship_galaxy.png`).
- `pages/<страница>/` — панели готовых страниц.

Постоянные ссылки для генерации «по образцу»: `https://raw.githubusercontent.com/Vince737/moydodr-art/main/sheets/<имя>.png`
