# Третья редакция — эталонные листы персонажей и правила промптов

Назначение: по этим описаниям генеративная модель рисует каждого персонажа один раз (character sheet), Саша утверждает лист, и дальше все панели рисуются «по образцу» этого листа (Flux Kontext или аналог с картинкой-референсом). Описания согласованы с векторной редакцией, чтобы читатель узнал тех же людей.

## Общий стиль (добавляется к каждому промпту)

```
painted comic book illustration, confident ink outlines, cel shading with soft gradients,
cinematic lighting, restrained palette (deep space blue, amber, teal, bone white),
clean composition, no text, no letters, no speech bubbles, no watermark
```
Негатив (если модель принимает): `text, caption, lettering, logo, watermark, extra fingers, deformed hands, blurry`.

Соотношения сторон под нашу раскладку: панель-половина — 3:4 (портрет), широкая панель — 16:9 или 3:2, полоса — 2:1.

## Порядок работы

1. Листы персонажей: по одному промпту на человека, 3:4, по 2–4 варианта, Саша выбирает.
2. Пробная страница — 27 («Встреча»): четыре панели, из них две портретные (шлюз; разговор у окна).
3. Для каждой панели: промпт = [стиль] + [место] + [персонажи по листам] + [действие, эмоция, ракурс]. Генерация с референсом листа.
4. Картинки — в папку `Мойдодр/art/<страница>/<панель>.png`; движок кладёт их слоем `("image", {"src": ...})` под пузыри и подписи.
